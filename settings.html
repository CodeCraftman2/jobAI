Gateway base URL
Full URL of any OpenAI- or Anthropic-compatible endpoint, without /chat/completions or /messages. The API format is detected automatically
API key
Key for the gateway above
Credential kind
How the key is sent. When set, only that kind is used (no fallback). Auto picks one for the endpoint
API format
Request style the gateway speaks. Auto uses Anthropic Messages for api.anthropic.com and OpenRouter, OpenAI-compatible for everything else
Model list
One model per line. The first entry is the default; the rest are tried if it fails
Free models only
When Auto-pick runs, test only models the gateway marks as free (Kilo and OpenRouter do; NVIDIA does not, so all of its models are tested)
Model discovery
When the model list is empty, test the gateway's chat models at launch and use the fastest ones that answer (same as Auto-pick). A model that fails is skipped for a few minutes and retried later
Test API
Checks that the base URL, API key, credential kind and format are accepted (uses the values above, saved or not)
